# Отчет по выбору вакансии для стажировки

## Выбранная компания

**Название:** Navio

**Сфера деятельности:** Разработка систем автономного вождения и функциональной безопасности транспортных средств

**Описание компании:**

Navio — компания, специализирующаяся на создании передовых решений в области автономного транспорта и систем безопасности. Компания занимается разработкой и внедрением технологий автономного вождения, уделяя особое внимание функциональной безопасности транспортных средств в соответствии с международными стандартами.

Основные направления деятельности компании:
- Разработка систем автономного вождения для коммерческого транспорта
- Создание и тестирование систем функциональной безопасности
- Интеграция машинного обучения в системы управления автономным транспортом
- Работа с международными стандартами безопасности (ISO 26262, ISO/PAS 08800)

Компания работает с крупными производителями транспортных средств, включая китайские автомобильные концерны, и участвует в проектах по внедрению автономных систем в грузовой транспорт.

## Описание вакансии

**Должность:** Тестировщик функций безопасности автономного транспорта

**Специальность:** QA Engineer / Тестировщик (соответствует списку специальностей School 21)

**Тип занятости:** Полная занятость (40 часов в неделю)

**Продолжительность стажировки:** 3 месяца

**Функциональное подразделение:** Отдел обеспечения качества и функциональной безопасности

## Основные обязанности

1. **Разработка и выполнение тестовых сценариев:**
   - Создание тестовых планов для проверки функций безопасности
   - Разработка тест-кейсов на основе технических требований безопасности (TSR)
   - Выполнение ручного и автоматизированного тестирования

2. **Автоматизация тестирования:**
   - Разработка автоматизированных тестов на Python с использованием pytest
   - Создание и поддержка фреймворков автоматизации тестирования
   - Интеграция тестов в CI/CD процессы

3. **HIL-тестирование (Hardware-in-the-Loop):**
   - Проведение тестирования в HIL-среде
   - Работа с симуляторами (CARLA) для создания тестовых сценариев
   - Тестирование интеграции программного и аппаратного обеспечения

4. **Документирование:**
   - Создание технической документации по стандартам ISO 26262
   - Оформление отчетов о результатах тестирования
   - Ведение документации по найденным дефектам

5. **Работа с системами безопасности:**
   - Тестирование тормозных систем и систем управления автономных транспортных средств
   - Проверка ML-компонентов в системах восприятия и планирования
   - Анализ критических сценариев безопасности

  - Понимание принципов тестирования ПО
  - Опыт работы с системами контроля версий (Git)
  - Навыки работы с Linux

- **Личные качества:**
  - Внимательность к деталям
  - Аналитическое мышление
  - Готовность к обучению
  - Способность работать в команде

### Желательные навыки:

- Знакомство с pytest или другими фреймворками автоматизации
- Базовое понимание автомобильных систем
- Знание английского языка на уровне чтения технической документации
- Опыт работы с CI/CD системами

## Условия стажировки

**Наставничество:** Компания предоставляет куратора из числа старших QA-инженеров, который будет:
- Давать регулярную обратную связь по выполненным задачам
- Помогать с адаптацией к процессам компании
- Проводить код-ревью автоматизированных тестов
- Оценивать прогресс и результаты работы

**График работы:**
- Полная занятость: 40 часов в неделю (5 дней по 8 часов)
- Гибкий график начала рабочего дня
- Возможность частичной удаленной работы

**Развитие и обучение:**
- Доступ к внутренней базе знаний компании
- Участие в командных митингах и обсуждениях
- Возможность изучения стандартов ISO 26262 и других отраслевых стандартов
- Практический опыт работы с реальными проектами автономного транспорта

**Проекты:**
В рамках стажировки предполагается участие в следующих типах проектов:
- Тестирование систем безопасности для грузовых автомобилей (например, SINOTRUK C7H)
- Разработка автоматизированных тестов для ML-компонентов
- Создание тестовых сценариев в симуляторе CARLA
- Работа над документацией по стандартам функциональной безопасности

## Технологии и инструменты, с которыми предстоит работать

- **Языки программирования:** Python
- **Фреймворки тестирования:** pytest
- **Симуляторы:** CARLA (симулятор автономного вождения)
- **Системы:** HIL (Hardware-in-the-Loop) тестовые стенды
- **Контроль версий:** Git
- **CI/CD:** Jenkins / GitLab CI
- **Документация:** Confluence, JIRA
- **Стандарты:** ISO 26262, ISO/PAS 08800, HARA, V-Model

Выбранная вакансия тестировщика функций безопасности в компании Navio полностью соответствует требованиям стажировки School 21 и предоставляет отличную возможность для получения практического опыта в высокотехнологичной области автономного транспорта. 

Работа в этой должности позволит:
- Получить опыт работы с международными стандартами безопасности
- Развить навыки автоматизации тестирования
- Освоить специализированные инструменты и технологии
- Поработать над реальными проектами для крупных автопроизводителей
- Получить ценный опыт в перспективной и быстрорастущей индустрии автономного транспорта

Компания Navio обеспечивает все необходимые условия для успешного прохождения стажировки, включая менторскую поддержку, доступ к современным технологиям и возможность работы над значимыми проектами.
